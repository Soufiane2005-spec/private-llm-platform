# Private LLM Platform

Private LLM Operations and Benchmarking Platform.

## Objective

Build a private platform for deploying, managing, monitoring and benchmarking Large Language Models on Kubernetes.

## Main Technologies

- Kubernetes
- Docker
- Proxmox
- FastAPI
- PostgreSQL
- Redis
- Ollama
- vLLM
- Prometheus
- Grafana
- GitHub Actions

## Main Features

- LLM deployment and management
- Ollama and vLLM support
- Asynchronous job processing
- LLM benchmarking
- Resource monitoring
- Performance recommendations
- Authentication and authorization
- CI/CD
- Kubernetes deployment

## Repository Structure

- `infrastructure/` - Infrastructure and Proxmox automation
- `kubernetes/` - Kubernetes manifests
- `services/` - Application backend services
- `frontend/` - Management dashboard
- `docs/` - Technical documentation
- `.github/` - GitHub configuration and CI/CD

## Status

Project under active development.
