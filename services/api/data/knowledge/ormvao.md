# Présentation synthétique de l'ORMVAO

L'Office Régional de Mise en Valeur Agricole de Ouarzazate, appelé ORMVAO,
est l'organisme d'accueil du projet.

Dans le cadre du rapport de stage, l'ORMVAO est présenté comme un organisme
intervenant dans le développement et la mise en valeur du secteur agricole
dans sa zone d'intervention.

Le projet Private LLM Platform a été réalisé dans ce contexte professionnel,
avec un objectif de maîtrise de l'infrastructure et de traitement privé des données.

> Les marchés, fournisseurs, bons de commande et projets fournis dans ce pack
> sont exclusivement des données synthétiques de démonstration.
