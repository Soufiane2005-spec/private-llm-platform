# Irrigation — base documentaire de démonstration

L'irrigation est un domaine important des projets agricoles suivis dans la base de démonstration.

## Types de projets
- Irrigation localisée.
- Réhabilitation de canaux.
- Pompage.
- Modernisation des réseaux.
- Économie d'eau.

## Indicateurs suivis
Chaque projet d'irrigation de démonstration contient une zone, une surface en hectares,
un nombre estimé de bénéficiaires, un pourcentage d'avancement, un statut
et un service responsable.
