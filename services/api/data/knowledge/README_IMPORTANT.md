# IMPORTANT — Jeu de données de démonstration

Ce dossier contient des **données synthétiques et fictives** créées uniquement
pour démontrer les capacités RAG de la Private LLM Platform pendant une soutenance.

Ces données ne sont **pas** des données officielles de l'ORMVAO.
Elles ne doivent pas être présentées comme des marchés réels, des fournisseurs réels,
des montants officiels ou des procédures officielles.

Pour une utilisation réelle, remplacez les fichiers CSV de démonstration par des exports
validés provenant des systèmes ou documents autorisés de l'organisation.
