# Documentation de démonstration — Procédures internes

IMPORTANT : les procédures décrites ici sont fictives et servent uniquement à tester le chatbot RAG.

## Création d'une demande interne

Une demande interne de démonstration doit préciser :

- le service demandeur ;
- l'objet de la demande ;
- le niveau de priorité ;
- une description claire du besoin ;
- les éventuelles pièces jointes nécessaires.

## Priorités

Trois niveaux de priorité sont utilisés dans cette documentation de démonstration :

- normale ;
- importante ;
- urgente.

Une demande urgente doit contenir une justification expliquant pourquoi un traitement rapide est nécessaire.

## Validation

Une demande nécessitant une validation est transmise au responsable du service concerné avant son traitement final.

## Archivage

Après clôture, la demande peut être conservée dans l'historique afin de permettre une consultation ultérieure.
